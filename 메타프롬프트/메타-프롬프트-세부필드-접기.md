# 메타프롬프트 — 세부 필드 접기

## 목표 (사용자 요구 원문 포함)
사용자: "세부 필드값들을 처음부터 펼쳐서 보여줄 필요는 없다"
→ 현재 프리셋 카드가 필드 값 행을 처음부터 5개까지 펼쳐서 보여줌. 이를 기본은 접어두고 필요할 때만 펼치도록 변경.

## 변경 범위 (파일별)
- `popup/popup.js` — `buildFieldCopyRows(fields)` 반환 HTML을 접힌 상태로 변경. 기본 `hidden`, 토글 버튼으로 펼치기/접기.
- `popup/popup.css` — 필요 시 `.field-copy-toggle` 스타일 미세 조정 (기존 스타일 재사용)
- `dist/` — `npm run build`로 재생성
- 테스트 — 기존 `test:replay`/`test:qa` 영향 없음, 수동: 카드가 기본 접혀 있고 버튼 클릭 시 펼쳐지는지

## 구현 상세
- 현재: `rows.slice(0,5)`는 보이고 나머지는 `hidden` + "N개 더보기" 토글. 5개 이하면 전부 보임.
- 변경: **전체**를 `hidden`으로 시작. 카드에는 `세부 필드 보기 (N개)` 버튼 하나만 보임. 클릭 시 `field-copy-list`의 `hidden`을 토글하고 버튼 텍스트를 `접기` ↔ `세부 필드 보기 (N개)`로 변경.
- 구현: `buildFieldCopyRows`에서 `rows` 전체를 하나의 `field-copy-list hidden` 컨테이너에 넣고, 앞에 토글 버튼을 둠. 토글 버튼은 `data-toggle-fields`를 유지해 기존 `renderList`의 이벤트 리스너와 호환되도록 하되, 대상 선택자를 `data-fields-container` 또는 `field-copy-list`로 변경.
- 기존 `MAX_VISIBLE` 분기 제거 — 단순화.
- 이벤트: `renderList`에서 `toggleBtn` 클릭 시 `list.classList.toggle('hidden')` 및 텍스트 교체.

## MUST NOT
- 프리셋 데이터/저장 로직 변경 금지
- 복사 버튼 기능 유지 — 펼쳐진 후 복사 가능해야 함
- 필드 값 마스킹(`••••••`), `나중에 입력`, `클릭` 등 표시 로직 유지

## 검증 방법
- `npm run check` — exit 0
- `npm run build` — exit 0
- 수동: 프리셋 카드에서 세부 필드가 기본 숨겨져 있고, "세부 필드 보기 (N개)" 클릭 시 펼쳐지며 복사 버튼 동작하는지
- `npm run test:replay` — 181/181 유지
