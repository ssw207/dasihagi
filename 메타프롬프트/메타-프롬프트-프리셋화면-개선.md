# 메타프롬프트 — 프리셋 화면 개선 (사이트별 섹션)

## 목표 (사용자 요구 원문 포함)
사용자: "프리셋 화면 개선. A사이트에서. 제휴사오픈세팅 이런식으로 프리셋들을 저장하고싶은데 지금 구조는 구별이안됨" → 선택 2
→ 프리셋 목록을 사이트 도메인 기준으로 자동 섹션 구분. 예: `A사이트` 섹션 아래에 `제휴사오픈세팅`, `정산세팅` 2개가 모여 보이게. 저장 구조 변경 없이 `urlPatterns[0]`을 기준으로 렌더링만 개선.

## 변경 범위 (파일별)
- `popup/popup.html` — 목록 컨테이너 `#preset-list`는 유지, 섹션 헤더는 JS에서 동적 생성 (HTML 구조 변경 없음)
- `popup/popup.js` — `renderList()`를 사이트별 그룹 렌더링으로 교체. `getPresetPatterns(p)[0]`을 키로 그룹화, `formatPatternMeta` 대신 섹션 헤더에 사이트명 표시. `visiblePresets()` 결과를 `Map<siteKey, preset[]>`로 묶어 섹션별로 렌더. 선택 삭제 바는 섹션 밖 유지. 검색/정렬은 이번 범위 밖.
- `popup/popup.css` — 섹션 헤더 `.preset-section` `.preset-section-head` 스타일 추가 (도메인명 + 개수 배지, 구분선)
- `test/` — 기존 `test:replay`/`test:qa`에 영향 없음. 수동 확인: A사이트 프리셋 2개 + B사이트 1개 생성 시 2개 섹션으로 나뉘는지
- `dist/` — `npm run build`로 재생성

## 구현 상세
### 그룹 키
- `siteKey = normalizeSiteKey(preset)` — `getPresetPatterns(preset)[0]` → `urlToSiteKey()` 유사 로직. `patternToSiteLabel()`에서 `host[:port]` 추출 후 소문자, `*.example.com`은 `example.com`로 표시, 없으면 `(패턴 없음)` 또는 `(미지정)`. 포트 포함 시 `127.0.0.1:3000` 그대로.
- 키가 없으면 `(패턴 없음)` 섹션으로

### 렌더링 순서
1. `shown = visiblePresets()` (필터 적용 후)
2. `groups = Map<string, preset[]>` — `shown` 순회하며 `siteKey`로 push. 삽입 순서는 첫 등장 순서 유지(사용자가 만든 순서대로 섹션 등장) 또는 알파벳 정렬 — **삽입 순서 유지**로 결정 (A사이트 먼저 만든 섹션이 위).
3. 각 그룹마다 `section = div.preset-section` 생성 → `head = div.preset-section-head`에 `<span class="section-site">siteKey</span><span class="badge section-count">N개</span>` + `list = div.preset-section-list`에 카드들 append
4. 기존 카드 렌더 로직(`preset-card` 생성)은 그대로 재사용, 단 `presetList`에 직접 append 대신 `sectionList`에 append
5. 빈 상태(`noneAtAll`/`noneVisible`)는 기존과 동일 — 섹션 생성 전 early return
6. `updateSelectBar()`는 섹션과 무관하게 `shown` 기준으로 동작

### 스타일
- `.preset-section { margin: 12px 0 8px; }`
- `.preset-section-head { display:flex; align-items:center; gap:6px; padding:6px 2px; border-bottom:1px solid #e5e7eb; font-size:12px; font-weight:700; color:#374151; }`
- `.preset-section-head .section-site { flex:1; overflow:hidden; text-overflow:ellipsis; white-space:nowrap; }`
- `.section-count { background:#e5e7eb; border-radius:10px; padding:2px 6px; font-size:11px; color:#4b5563; }`
- 기존 `.preset-card`는 섹션 안에서 그대로

### MUST NOT 위반하지 않기
- 저장 스키마 변경 금지 — `preset.folder` 같은 필드 추가 없음
- `urlPatterns` 정규화 로직 중복 금지 — 기존 `getPresetPatterns()` 재사용
- 사이트별 하드코딩 금지 — 도메인은 패턴에서 자동 추출

## MUST NOT
- 프리셋 데이터 스키마 변경 금지 (folder/tag 필드 추가 금지)
- `urlPatterns` 파싱을 새로 발명 금지 — 기존 `getPresetPatterns`/`normalizeHost` 재사용
- 정렬 기준을 이름으로 강제하지 않음 — 삽입 순서 유지
- `groups` (그룹 실행) UI에 영향 금지 — 프리셋 뷰만 변경
