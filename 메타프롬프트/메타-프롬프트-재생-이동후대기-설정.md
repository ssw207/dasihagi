# 메타프롬프트 — 페이지 이동 후 쉬는 동작 설정

## 목표

사용자 요구 원문: **「페이지이동후 쉬는동작이 있는데 설정으로 제어할수 있게해줘. 사내사이트는 봇 제한 같은게 없어서 그때는 빠른속도로 해도됨」**

여정 재생 시 페이지 이동 뒤 대기(쉬는 동작)를 사용자가 조절한다. 사내처럼 봇 제한이 없으면 **빠름**, 외부 사이트는 **보통/느림**을 고를 수 있게 한다.

## 변경 범위

| 파일 | 내용 |
|------|------|
| `background.js` | 설정 읽기, 이동 후 추가 대기·폴링 상한에 배율/고정 ms 적용 |

| `test/record-replay-verify.mjs` | 빠름일 때 이동 후 대기가 짧아지는지 |
| `REQUIREMENTS.md` `decisions.md` `README.md` | R17, D31 |

## 구현 상세

1. `chrome.storage.local` 키 `ui:replayPace` (또는 `settings.replayPace`): `fast` / `normal` / `slow`. 기본 `normal`.
2. **fast**: 이동 후 추가 대기 거의 없음(로드 complete만). delay 상한을 낮춤.
3. **normal**: 지금과 동일(녹화 delay + 이동 대기).
4. **slow**: 이동 후 여유 대기(예: +800ms) — 외부 사이트용.
5. popup 프리셋 탭 더보기 또는 목록 하단에 **재생 속도** 선택. 전역 설정(프리셋별 아님) — 사내/외부를 그때그때 바꿀 수 있게.
6. 녹화 자체 delay 기록은 바꾸지 않음. 재생에만 적용.

## MUST NOT

- 사이트 하드코딩(사내 도메인 목록) 금지. 사용자가 설정으로 고른다.
- 기존 테스트 삭제 금지.
- 암호화/스키마 파괴 변경 금지.
