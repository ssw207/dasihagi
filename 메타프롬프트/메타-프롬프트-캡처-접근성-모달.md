# 메타프롬프트 — 캡처 접근성 및 저장 모달 닫힘

## 목표 (사용자 요구 원문 포함)
사용자: "시작방법 접근성, 저장시 모달 안닫힘"
→ 두 가지 UX 버그
1. 캡처 시작 방법이 접근하기 어렵다 — 현재 편집 화면(`⋯ → 편집 → 캡처 모드 시작`) 2단계 깊이에 숨겨져 있어 목록에서 바로 캡처를 시작할 수 없음
2. 캡처 패널에서 저장 시 모달이 닫히지 않는다 — `저장` 클릭 후 `저장 완료!`만 뜨고 패널이 그대로 남아 다음 필드를 가리거나 수동으로 `취소`를 눌러야 함

## 변경 범위 (파일별)
- `popup/popup.js` — 프리셋 카드의 `⋯` 메뉴에 `캡처` 항목 추가 (`data-act="capture"`). 기존 `record/edit/delete` 옆에 배치해 목록에서 원클릭으로 캡처 시작 가능. `handlePresetAction('capture')`는 이미 구현되어 있으므로 메뉴만 추가.
- `content.js` — `saveField()` 성공 시 패널을 닫도록 수정. 현재는 `panelTarget` 하이라이트만 제거하고 `showStatus('저장 완료!')`만 하고 `closePanel()`을 호출하지 않음. 수정 후 `showStatus` 후 600ms 뒤 `closePanel()` 호출로 모달이 자동으로 닫히되, 캡처 모드(`capture.active`)는 유지되어 다음 필드 하이라이트는 그대로.
- `dist/` — `npm run build`로 재생성
- 테스트 — `check`/`replay`/`qa` 영향 없음, 수동 확인

## 구현 상세
### 1) 시작 접근성
- `popup.js:renderList`에서 카드 메뉴 HTML을:
  ```html
  <button data-act="record">녹화</button>
  <button data-act="capture">캡처</button>
  <button data-act="edit">편집</button>
  <button data-act="delete">삭제</button>
  ```
  로 변경. 순서는 녹화(전체) → 캡처(한 칸) → 편집 → 삭제로 논리적. `handlePresetAction('capture')`는 이미 `CAPTURE_START`를 `currentTabId`로 전송하고 `window.close()`로 팝업을 닫아 페이지에서 바로 필드를 고를 수 있게 함.
- 접근성: 메뉴 항목이므로 키보드 Tab/Enter로도 접근 가능, 기존 `closeAllMenus` 로직 그대로.

### 2) 저장 시 모달 닫힘
- `content.js:saveField()` 내부 `chrome.runtime.sendMessage({type:'CAPTURE_SAVE_FIELD',...}, (resp)=>{...})` 성공 분기:
  ```js
  if (!resp || !resp.ok) { showStatus(...); return; }
  if (panelTarget) panelTarget.classList.remove('fp-capture-input');
  panelTarget = null;
  showStatus('저장 완료!');
  setTimeout(() => closePanel(), 600);
  ```
  로 변경. `closePanel()`은 `panelEl`을 제거하고 `panelTarget=null`로 하며, `capture.active`는 건드리지 않아 하이라이트는 유지. 600ms는 토스트를 읽을 최소 시간.
- 실패 시에는 `showStatus(..., true)`만 하고 닫지 않아 에러 메시지를 확인할 수 있게 함.

## MUST NOT
- 캡처 하이라이트 로직(`startCaptureMode`/`highlightAll`) 변경 금지 — 시작 접근성만 개선
- 저장 데이터(`CAPTURE_SAVE_FIELD` payload) 변경 금지 — 모달 닫힘만
- 기존 `record`/`edit`/`delete` 메뉴 순서 외 기능 변경 금지
- `capture.replaceFieldId`(다시 찍기) 로직에 영향 금지

## 검증 방법
- `npm run check` — exit 0
- `npm run build` — exit 0
- 수동 1: 프리셋 목록에서 `⋯ → 캡처` 클릭 → 팝업 닫히고 페이지에 점선 하이라이트가 뜨는지, `Esc` 없이도 바로 필드 클릭 가능한지
- 수동 2: 캡처 패널에서 표시 이름/값 입력 → `저장` → 0.6초 후 패널이 자동으로 닫히고 하이라이트는 남아 다음 필드를 바로 고를 수 있는지, 저장 실패 시에는 패널이 유지되는지
- `npm run test:replay` — 181/181 유지
