# 메타프롬프트 — 채움 초안 스펙 (구현 없음)

## 목표

사용자 요구 원문: **「다음 단계진행」** (직전: AS-IS/TO-BE로 이해한 P0를 다음 BMAD 단계로)

브레인스토밍 P0(채움 초안)을 `bmad-spec` 계약으로 굳힌다. 제품 코드는 건드리지 않는다.

## 변경 범위

| 경로 | 작업 |
|------|------|
| `_bmad-output/specs/spec-fill-as-draft/` | SPEC.md, 컴패니언, .memlog.md 생성 |
| `메타프롬프트/메타-프롬프트-채움초안-스펙.md` | 이 파일 |
| 제품 런타임 (`src/`, `dist/`, popup 등) | 변경 없음 |
| `REQUIREMENTS.md` / `기획서.md` | 이 라운드에서 갱신 없음 (스펙 승인 후 구현 라운드에서) |

## 구현 상세

- slug: `fill-as-draft`
- 입력: 브레인스토밍 결정, 사용자 확인 AS-IS/TO-BE, REQUIREMENTS R1~R18, 기획서 비목표, 유즈케이스 U1/U7/U12
- CAP: 손댈 칸, 빈 칸 의도, 리픽, 위험 클릭 금지, 프리셋별 속도, 첨부 스톱, 스크럽 내보내기
- P1(사이드패널, PIN, 페르소나 칩, 날짜 변수)은 이 스펙 Non-goals

## MUST NOT

- 확장 코드 수정, dist 빌드, 테스트 삭제
- 클라우드 동기화·엑셀 대량·오픈런·캡차를 범위에 넣기
- 손댈 칸 표시 방법을 사용자 확인 없이 확정하기 (open question)

## 검증

- SPEC.md가 Spec Law 1~8을 만족
- 제품 파일 git diff 없음
- 가정·미결 질문을 사용자에게 짧게 제시
