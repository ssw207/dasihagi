## 1. 대상 제품

- 이름: **폼 프리셋** (Chrome 확장 프로그램, Manifest V3)
- 하는 일: 특정 사이트의 폼에 들어가는 값을 한 번 저장해 두고, 버튼 한 번으로 자동으로 채워준다.
- 쓰는 사람: 반복적으로 폼을 채워야 하는 일반 사용자 (개발자 아님)

## 2. README가 담을 내용 (사용자 관점, 순서대로)

README는 아래 흐름만 담는다. **이 외의 정보는 넣지 않는다.**

### 시작하기 전에
- 필요한 것: Chrome 브라우저, Node.js
- 확인 명령: `node --version` — 버전이 출력되면 OK

### 1단계: 빌드
- 명령어: `npm run build`
- 실행하면 화면에 **복사할 경로**가 출력된다 (예: `C:\...\my-chrome-extension\dist`)
- "이 경로를 복사하세요" 라고 안내

### 2단계: 크롬에 확장 프로그램 로드
- `chrome://extensions` 열기 → 우측 상단 **개발자 모드** 켜기 → **압축해제된 확장 프로그램을 로드합니다** 클릭
- 1단계에서 복사한 **빌드 경로를 그대로 붙여넣기** (파일 선택 창의 경로 입력란에 붙여넣고 Enter)
- 성공 표시: 툴바에 "폼 프리셋" 아이콘 표시

### 3단계: 테스트 페이지에서 확인 (선택)
- 실제 사이트 없이 동작을 확인하려면: `test/test-form.html` 생성 명령어 제공 (이름/이메일/부서/체크박스/메모 입력란이 있는 페이지)
- 로컬 서버로 열기: `python3 -m http.server 8000` 또는 `npx serve` → 브라우저에서 `http://localhost:8000/test/test-form.html` 접속
- 파일 URL로 열 때는 확장 프로그램 설정의 **"파일 URL에 대한 액세스 허용"**을 켜야 한다는 안내 1줄

### 4단계: 프리셋 만들기
- 사이트 접속 → 확장 아이콘 클릭 → **+ 새 프리셋** → 이름 입력 → 사이트 주소가 자동 입력된 것 확인 → **저장**

### 5단계: 캡처 모드로 값 저장하기
- 프리셋의 **캡처** 클릭 → 페이지의 입력란이 파란 점선으로 표시됨
- 원하는 입력란 클릭 → 값 입력 → **저장** (여러 필드 반복 가능)
- 테스트 페이지 기준 저장 예시 1개: 이름=홍길동, 이메일=hong@test.com, 부서=엔지니어링

### 6단계: 프리셋 적용하기
- 확장 아이콘 → **적용** 클릭 → 모든 입력란이 채워지는지 확인

### 7단계: 자동 적용 (선택)
- 프리셋 편집 → **"페이지 진입 시 자동 적용"** 체크 → 저장 → 다음 접속부터 자동으로 채워짐

### 도움이 되는 팁
- 사이트 패턴 규칙 표: `example.com` / `*.example.com` / `example.com/admin/*` 3줄로만 요약
- 문제가 생기면 (최대 4개, 각 1~2줄):
  - 값이 안 채워질 때 → 확장 프로그램 새로고침 + 페이지 새로고침
  - 아이콘이 안 보일 때 → 툴바에서 확장 고정(핀)
  - chrome:// 같은 크롬 내장 페이지 → 지원 안 됨
  - 사이트가 바뀐 뒤 값이 안 들어갈 때 → 캡처 다시 실행

## 4. 작성 규칙

1. 단계는 반드시 위 순서대로, 각 단계에 **"이렇게 되면 성공"** 체크 포인트 1개
2. 모든 명령어는 복사-붙여넣기 가능한 코드 블록 + 명령 목적 1줄 주석
3. 기본 셸은 bash. Windows cmd 대안은 `(Windows cmd: ...)`로 1줄 병기 (필요한 곳만)
4. 확장 UI 버튼 이름은 그대로 인용: **새 프리셋 / 캡처 / 적용 / 편집 / 자동 적용**
5. 한국어, 명사형·명령형으로 간결하게. 중복 표현, 감탄사, 수식어 금지
6. 작성 전 `package.json`을 읽어 빌드 명령(`npm run build`)이 실제 스크립트와 일치하는지 확인
7. 빌드 경로는 `npm run build`가 실제 출력하는 형식(절대 경로)으로 안내 — 경로를 고정해 쓰지 말고 "출력된 경로를 복사"로 표현
