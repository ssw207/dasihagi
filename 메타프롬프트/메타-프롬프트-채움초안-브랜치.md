# 메타프롬프트 — 채움 초안 구현 전 브랜치

## 목표

사용자 요구 원문: **「구현전 별도 브랜치 생성」**

채움 초안(SPEC-fill-as-draft) 구현이 master에 섞이지 않도록 브랜치만 만든다. 이 요청에서 구현·커밋하지 않는다.

## 변경 범위

| 경로 | 작업 |
|------|------|
| git 브랜치 `feature/fill-as-draft` | `master`에서 생성 후 체크아웃 |
| 제품 코드 | 변경 없음 |
| 커밋 | 하지 않음 |

## 구현 상세

- `git switch -c feature/fill-as-draft`
- 워킹트리 미커밋 파일은 그대로 가져간다 (커밋하지 않음)

## MUST NOT

구현 시작, master에 커밋, force push, 원격 설정 추측 푸시

## 검증

`git branch --show-current`가 `feature/fill-as-draft`
