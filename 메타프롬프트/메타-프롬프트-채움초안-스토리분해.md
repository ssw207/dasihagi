# 메타프롬프트 — 채움 초안 미결 확정 + 스토리 분해

## 목표

사용자 요구 원문: **「알아서 정하고 스토리로 쪼개」**

열린 질문 3개를 결정으로 닫고, SPEC을 재도출한 뒤 `stories.yaml`을 쓴다. 제품 코드 변경 없음.

## 구현 상세 (확정할 답)

1. 손댈 칸: 저장 값이 비면 자동 손댈 칸. 편집에서 켜고 끌 수 있음. 녹화 중 별 버튼 없음.
2. 위험 클릭: 일반 위험 글자 기본 목록 + 편집에서 표시/해제. 사이트 셀렉터 하드코딩 없음. `제출` 단독은 목록에 넣지 않음.
3. 스크럽: 그룹 포함. 필드 값만 비움.

체크포인트: 사용자가 위임을 명시했으므로 spec/done 모두 false.

## MUST NOT

코드 수정, CAP ID 재번호, 클라우드/엑셀/오픈런 범위 추가.
