# 메타프롬프트 — 더보기 점 3개

## 목표 (사용자 요구 원문 포함)
사용자: "더보기 대신 점 3개로"
→ 툴바의 `더보기` 텍스트 버튼을 `⋯`(점 3개) 아이콘 버튼으로 교체. 카드 메뉴의 `⋯`와 일관성.

## 변경 범위 (파일별)
- `popup/popup.html` — `#btn-more`의 텍스트 `더보기` → `⋯`, `aria-label="더보기"` 유지
- `popup/popup.css` — 필요 시 `.btn`의 `min-width` 조정으로 점 3개 버튼이 너무 크지 않게 (기존 카드의 ⋯ 버튼과 동일 스타일)
- `dist/` — `npm run build`로 재생성

## 구현 상세
- HTML: `<button id="btn-more" aria-label="더보기">⋯</button>`로 텍스트만 교체, `aria-haspopup`/`aria-expanded` 유지
- CSS: 기존 `.btn`은 `padding 7px 12px`로 점 3개에는 넓음. 툴바의 점 버튼에만 `min-width:32px; padding:5px 8px`를 이미 `.card-more > .btn`에 적용 중이므로, `#btn-more`에도 동일하게 적용하거나 `.toolbar-more > .btn`에 추가. 간단히 인라인 스타일 없이 CSS에서 `#btn-more { min-width:32px; padding:5px 8px }` 추가.

## MUST NOT
- 기능/메뉴 내용(내보내기/값 없이 내보내기/가져오기) 변경 금지
- 접근성(`aria-haspopup`, `aria-expanded`) 제거 금지

## 검증 방법
- `npm run check` / `npm run build`
- 수동: 툴바에 `⋯` 버튼이 보이고 클릭 시 메뉴가 뜨는지, 카드의 `⋯`와 시각적으로 일관되는지
