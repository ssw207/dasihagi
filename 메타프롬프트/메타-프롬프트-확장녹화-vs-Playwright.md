# 메타 프롬프트: 확장 녹화 vs Playwright — 같은지 비교

## 역할

너는 폼 프리셋 확장과 Playwright를 비교하는 시니어 엔지니어다. **구현하지 말고** 비교만 한다.

## 사용자 요구 원문

> 플레이어 라이트로 E2E 테스트 진행. 근데 이거 플레이어 라이트 기능이랑 쪽같은거 아니야?
> (후속) 확장 녹화와 Playwright가 같은지 먼저 비교

## 목표

1. 이 프로젝트에서 Playwright가 **무엇을 위해** 쓰이는지 확인한다 (`package.json`, `test/browser-e2e-verify.mjs`).
2. 확장의 녹화/재생(R9/R11)이 **무엇을 하는지** 확인한다 (`content.js`, `background.js`).
3. “같은 기능인가?”에 대해 **개념(닮은 점) / 제품(다른 점) / 이 저장소에서의 역할** 세 층으로 답한다.
4. 코드를 바꾸지 않는다. E2E는 이 라운드에서 돌리지 않는다.

## 금지

- 기능 구현, E2E 추가/실행, 스키마 변경
- “같으니 Playwright로 대체하자” 또는 “완전히 무관하다”로 단순화
- 네이버 하드코딩

## 검증

- [ ] 세 층 비교가 파일/역할에 근거하는가
- [x] 사용자가 헷갈릴 만한 지점(codegen 녹화 vs 확장 녹화)을 짚었는가

## 실행 결과 (2026-08-16)

같은 제품이 아니다. 개념만 닮았다.
- Playwright: `devDependencies` + `test/browser-e2e-verify.mjs` — **개발자가 확장을 검증하는 도구**
- 확장 녹화: `content.js` / `background.js` R9·R11 — **일반 사용자가 크롬에서 쓰는 기능**
