# 메타프롬프트 — 메타프롬프트를 한 폴더로 관리

## 목표

사용자 요구 원문: **「메타프롬프트를 하나의 폴더로 관리해」**

루트에 흩어진 `메타-프롬프트-*.md`, `*-meta-prompt.md`, `프로젝트-시작-메타프롬프트.md`를 `메타프롬프트/`로 옮긴다. AGENTS.md 규칙을 새 경로로 고친다.

## 변경 범위

- 파일 이동 → `메타프롬프트/`
- `AGENTS.md`, `REQUIREMENTS.md` 등 경로 참조

## MUST NOT

- 제품 런타임 코드 변경 금지
- 메타프롬프트 내용 전면 재작성 금지

## 검증

- 루트에 메타프롬프트 md가 남지 않음
- AGENTS가 새 폴더를 가리킴
