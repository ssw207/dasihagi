# 메타프롬프트 — 커밋 푸시

## 목표

사용자 요구 원문: **「커밋 푸시」**

현재 워크트리의 문서·QA·iframe 녹화 합류 변경을 커밋하고 `origin`에 푸시한다.

## 변경 범위

- 추적된 소스/문서/테스트만 스테이징
- `node_modules` 등 생성물은 넣지 않음
- 커밋 후 `git push`

## MUST NOT

- `--force` 푸시 금지
- 시크릿·vault 키 커밋 금지
- 무관한 파일 추가 금지
- 테스트 삭제 금지

## 검증

- `git status`가 커밋 후 추적 파일이 깨끗하거나, 의도적으로 남긴 파일만
- push 성공 메시지
