# 메타 프롬프트: 프리셋 등록 "엔터 기반 순차 입력" 전환

## 역할
너는 Chrome 확장 프로그램의 프리셋 등록 기능을 수정하는 시니어 프론트엔드 엔지니어다. 아래 요구사항을 **먼저 실제 코드베이스를 탐색한 뒤**, 최소 변경 원칙으로 구현하고 검증까지 완료해야 한다.

## 배경 / 현재 동작
- 프리셋 등록은 "DOM 선택 → 이름/값 입력 → 저장" 순서로 진행된다.
- DOM 선택은 **클릭**, 입력은 **키보드**로 수행한다.
- 이름 입력 폼과 값 입력 폼이 분리되어 있다.
- **문제**: 프리셋 등록 폼 패널 내부의 클릭이 DOM 선택(pick) 모드의 클릭으로 처리된다. 그래서 이름을 입력한 뒤 값 입력창을 클릭하면 DOM 재선택 등으로 상태가 꼬인다.

## 목표 동작 (변경 후)
키보드만으로 폼 간 이동이 가능해야 하며, 폼 패널 내부 클릭은 절대 DOM 선택을 트리거하지 않아야 한다.

1. **DOM 선택**: 페이지(DOM) 클릭 선택 방식은 그대로 유지한다.
2. **이름 입력**: 이름 입력창에 타이핑 후 **Enter** → 이름 확정 + 값 입력창으로 포커스 이동. (값 입력창이 숨겨져 있다면 이 시점에 표시)
3. **값 입력**: 값 입력창에 타이핑 후 **Enter** → 프리셋 **저장 후 등록 완료** (기존 저장/완료 로직 재사용).
4. **폼 패널 내부 클릭**: 이름/값 입력창, 버튼 등 폼 패널 내부의 모든 클릭은 순수한 폼 조작(포커스 이동 등)으로만 동작하며 DOM 선택(pick) 모드가 발동하면 안 된다.

## 구현 요구사항

### 1. 코드베이스 탐색 (구현 전 필수)
- DOM 선택(pick) 모드의 상태 관리와 전역/문서 클릭 리스너 위치를 찾아라.
- 이름/값 입력 폼의 DOM 구조, 저장 핸들러, 완료 처리 로직을 찾아라.
- 기존 Enter/Esc 키 핸들링이 있는지 확인하라.

### 2. 폼 내부 클릭 격리
- 폼 패널 영역을 pick 모드 클릭 처리에서 명시적으로 제외하라. (예: `closest('[data-preset-form]')` 체크, 별도 이벤트 레이어, `stopPropagation` 등 — 기존 코드 구조에 맞는 최소 변경 방식 선택)
- 페이지 본문 클릭으로 DOM을 선택하는 기존 동작은 반드시 유지하라.

### 3. 엔터 기반 순차 입력
- 이름 input에서 Enter → 값 input으로 포커스 이동 (`preventDefault`로 폼 제출 방지).
- 값 input에서 Enter → 기존 저장 로직 호출, 저장 후 완료 상태로 전환 (폼 닫기/완료 표시는 기존 UX 유지).
- **한글/IME 조합 중 Enter는 반드시 무시하라** (`isComposing` / composition 이벤트 처리 필수 — 한글 입력에서 Enter가 조합 확정 키로 쓰이므로).
- Enter가 기존에 다른 동작(검색, 저장 등)에 이미 쓰인다면 충돌하지 않게 통합하라.

### 4. 기존 로직 보존
- 이름/값 검증, 저장, 완료 로직과 데이터 구조는 변경하지 않는다. 포커스 이동·표시 전환만 추가/수정한다.
- DOM 선택(클릭) 로직, 프리셋 목록·편집 등 다른 기능에 영향을 주지 않는다.

## 금지 사항 (MUST NOT)
- 저장 로직, 데이터 구조, 프리셋 스키마 변경 금지.
- DOM 선택(클릭) 방식 제거·변경 금지.
- 폼 패널 외 영역의 클릭 동작 변경 금지.
- 다른 프리셋 기능(목록, 삭제, 편집) 수정 금지.
- 타입 에러 억제(`as any`, `@ts-ignore`) 금지.

## 검증 (구현 후 반드시 수행)
- [ ] 이름 입력 → Enter 시 값 입력창에 포커스가 이동하는가 (클릭 없이)?
- [ ] 값 입력 → Enter 시 기존과 동일하게 저장되고 등록 완료 상태가 되는가?
- [ ] 폼 패널 내부를 클릭해도 DOM 선택(pick) 모드가 발동하지 않는가?
- [ ] 페이지 본문 클릭 시 DOM 선택은 여전히 동작하는가?
- [ ] 한글 입력(IME 조합 중)에서 Enter로 인한 오동작이 없는가?
- [ ] 빈 이름/빈 값 등 기존 검증 동작이 그대로 유지되는가?
- [ ] 변경 파일에서 LSP 진단 오류가 없는가?
