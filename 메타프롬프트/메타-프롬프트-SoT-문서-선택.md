# 메타프롬프트 — SoT 문서 선택

## 목표

사용자 요구 원문: **「지금 문서중에 sot 어떤걸 쓰면좋을까?」**

구현 없이 기존 문서 역할을 기준으로 Source of Truth를 추천한다.

## 변경 범위

없음 (답변만). 코드·REQUIREMENTS·기획서 수정 금지.

## 구현 상세

- 이미 선언된 역할: REQUIREMENTS.md = 무엇을 해야 하는지 단일 기준
- 기획서 = 왜/범위/비목표
- README = 설치·사용
- decisions = 왜 그렇게 만들었는지
- 한 파일로 몰지 말 것. BMAD PRD를 새 SoT로 두지 말 것

## MUST NOT

제품 코드 변경, 새 PRD를 기존 문서 위에 올리기

## 검증
