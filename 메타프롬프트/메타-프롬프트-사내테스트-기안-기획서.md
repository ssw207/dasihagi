# 메타프롬프트 — 사내 테스트 한정 개발 기안 기획서

## 목표

사용자 요구 원문: **「사내 테스트 용도 한정으로이 플러그인을 디벨롭 하는 기안을 기획팅으로 회의후 기획서 작성」**

다시하기(dasihagi) Chrome 확장을 **사내 테스트 전용**으로 개발·파일럿하는 안을, 기획팅에서 확정한 뒤 **기안용 기획서**로 남긴다.

- 산출물 1: 기획팅 회의록 (안건·논의·결정·액션)
- 산출물 2: 기안 기획서 (승인권자가 범위·보안·비목표를 읽고 승인할 수 있는 문서)
- 기존 제품 기획서 `기획서.md`(역생성, 제품 범위)는 **덮어쓰지 않는다.** 기안과 역할을 나눈다.

근거: `기획서.md`, `REQUIREMENTS.md`(R1~R18), `README.md`, `유즈케이스-실사용자.md`, `decisions.md`(D1~D36), 버전 `0.1.0`. 미구현을 약속하지 않는다.

## 구현 상세

### 기획팅에서 확정할 결정 (기안에 반영)

1. **용도 한정**: 사내 스테이징·폐쇄망 어드민·로컬 테스트. 고객 대상·웹스토어·대외 배포 없음.
2. **사용자**: QA, 기획, 제휴 운영, 개발(스테이징). 전 직원 강제 설치 아님. 파일럿 소수부터.
3. **하지 않는 일**: 오픈런·캡차·보안키패드, 운영 결제·상신 자동 클릭, 실개인정보 프리셋, 클라우드 동기화.
4. **배포**: Chrome 개발자 모드 `dist/` 로드 또는 IT가 정한 내부 패키지. 스토어 심사 없음.
5. **보안**: 서버 없음, 프리셋 AES-256-GCM 로컬, 내보내기 JSON은 테스트 데이터만, 운영 비밀번호 저장 금지.
6. **기반**: 이미 있는 v0.1.0을 사내 파일럿 기준으로 공식화. 신규 기능 약속 없음.
7. **성공**: 테스트 계정 전환·반복 폼 입력 시간 감소, 칸 누락 감소. 매크로 성공률이 아님.

## MUST NOT

- 웹스토어 출시, 전사 필수 설치, 운영 자동 결제를 기안 범위에 넣지 않음
- 미구현 기능을 로드맵 약속처럼 쓰지 않음
- 기존 `기획서.md`를 기안으로 교체하지 않음
- 소스 코드 변경 금지
- 실명 없는 허위 결재란을 만들지 않음 — 역할만 (기획, QA, 개발, 보안/IT)
