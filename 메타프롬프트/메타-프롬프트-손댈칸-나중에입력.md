## 목표

사용자 요구 원문: **「Read `_bmad-output/specs/spec-fill-as-draft/stories/1-hand-edit-and-later-input.md` fully and implement it — the spec is the sole source of truth.」**

채움 대상 필드의 저장 값이 비면 **손댈 칸**으로 두고 재생은 채우지 않는다. 페이지에서 노랗게 남긴다. 편집에서 켜고 끌 수 있다. 셀렉터 실패만 누락이다. 고의 공백과 실패를 구분한다 (CAP-1, CAP-2).

## 구현 상세

- blob 안 `handEdit`(boolean). 채움 타입만: `text` `textarea` `select` `checkbox` `radio`. `click` `keydown` `navigate`는 아님.
- 읽기: 채움 타입 + 값 `''` + 키 없음 → `handEdit=true`. 저장 전까지 blob 일괄 재기록 없음.
- 녹화: 칸을 비워 두면 손댈 칸. 녹화 중 버튼 없음.
- 재생: 값 안 넣음, 노란 `fp-hand-edit`(input/change까지 유지). 초록 `fp-apply-flash`와 분리. 자동 스크롤 없음.
- 요소를 못 찾은 손댈 칸만 누락. 손댈 칸 성공은 실패 개수에 넣지 않음.
- 토스트: 채움 개수 / 손댈 칸 개수(라벨) / 누락 개수.
- 목록 카드 빈 손댈 칸: `나중에 입력`. 복사 버튼은 빈 값이면 비활성.
- 평문 `presets` 인덱스에 필드 값·`handEdit` 없음 (R6).

## MUST NOT

- 시각 매칭, 리픽, 위험 클릭, 첨부 스톱, 프리셋 속도, 스크럽.
- 녹화 엔진 교체, 캡처 모드 삭제, 클라우드, 사이트 하드코딩.
- 손댈 칸을 실패 개수에 넣기 (요소를 못 찾은 경우만 누락).
- 인덱스에 필드 값/플래그 넣기.
