# 메타프롬프트 — 최고속도 재생 추가

## 목표 (사용자 요구 원문 포함)
사용자: "지금 내가 클릭한 속도를 고려해서 선택하는데 말고 최고속도로 선택하게 하는 재생속도 추가"
→ 현재 재생은 녹화된 delay(클릭 간격)를 고려해 fast/normal/slow로 재현한다. 사용자가 녹화 때 천천히 클릭해도 재생 때는 즉시·최고속으로 채우길 원한다. 기존 3단계(빠름/보통/느림)에 더해 delay를 무시하고 즉시 적용하는 4번째 속도 "최고속도"를 추가한다.

## 변경 범위 (파일별)
- `background.js` — `normalizeReplayPace`, `paceDelayMs`, `paceAfterNavigateMs`, `paceTabWaitMs`, `paceWaitElementMs`, `resolvePresetPace`
- `content.js` — `paceDelayMs`, `paceWaitElementMs` (중복 정의), 동일하게 max 분기 추가
- `popup/popup.html` — 전역 재생 속도 세그먼트에 `최고속도` 버튼 추가, 편집 프리셋 속도에도 `최고속도` 버튼 추가 (기존 3개 → 4개)
- `popup/popup.js` — pace 버튼 클릭/표시 로직 (class `is-on` 토글, `SETTINGS_GET/SET` 값 처리) — 기존 하드코딩 배열에 'max' 추가
- `REQUIREMENTS.md` — R17, R22에 max 정의 추가, R17-2~4에 max 상수 기록
- `README.md` — 재생 속도 표에 최고속도 설명 추가
- `기획서.md` — 7.2 재생 속도 항목에 최고속도 추가 (선택)
- `test/record-replay-verify.mjs` — 최고속도 재생이 delay 무시(0) 검증 테스트 1건
- `test/qa-edge-verify.mjs` — SETTINGS 이상한 값은 normal, max는 허용 검증
- `dist/` — `npm run build`로 재생성

## 구현 상세
### 코드 값
- 내부 값: `'max'` (영문, 기존 fast/normal/slow와 일관)
- UI 라벨: `최고속도` (한국어, popup에 표시)
- 저장 키: `ui:replayPace`에 'max' 저장, 프리셋 `replayPace`에도 'max' 허용

### 타이밍 상수
- `paceDelayMs(raw, 'max') → 0` — 녹화 delay 완전 무시, 즉시 선택
- `paceAfterNavigateMs('max') → 0` — 페이지 이동 후 대기 없음 (fast와 동일)
- `paceTabWaitMs('max') → 5000` — 탭 complete 대기 최소 (fast 8000보다 짧게)
- `paceWaitElementMs('max') → 1000` — 요소 대기 최소 (fast 2500보다 짧게)
- `normalizeReplayPace('max') → 'max'` 유지, 그 외는 normal
- `resolvePresetPace` — 'max'도 프리셋이 전역을 덮는 후보에 포함

### UI
- `popup.html` `#presets-view .pace-seg` 에 `<button data-pace="max">최고속도</button>` 추가 (맨 앞 또는 맨 뒤 — 기존 빠름/보통/느림 뒤에 추가)
- `popup.html` `#ed-pace-row .pace-seg` 에 `<button data-ed-pace="max">최고속도</button>` 추가
- `popup.js`의 pace 버튼 핸들러가 `dataset.pace` 값을 그대로 `SETTINGS_SET`으로 전달 — 추가 분기 없이 동작하나, `is-on` 토글 배열에 'max' 포함 확인
- 편집 저장 시 `replayPace==='max'`면 blob에 저장, 평문 인덱스에는 미포함(R6 원칙 유지)

### 하위 호환
- 기존 프리셋의 `replayPace`가 없거나 ''이면 전역 따름 — max 추가 후에도 동일
- 레거시 값(fast/normal/slow) 그대로 동작, max는 신규 프리셋/전역에서만 발생

## MUST NOT
- 기존 fast/normal/slow 타이밍 변경 금지 — max만 0으로 추가
- 사이트 도메인/셀렉터 하드코딩 금지
- `secure-store.js` 암호화 로직 변경 금지
- 녹화 시 delay 기록 로직 변경 금지 — 재생 때만 무시
