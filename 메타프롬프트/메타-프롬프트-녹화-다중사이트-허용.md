# 메타 프롬프트: 녹화 중 방문 사이트 N개 자동 허용

## 역할

너는 Chrome 확장 프로그램(폼 프리셋, MV3)의 녹화/재생을 고치는 시니어 프론트엔드 엔지니어다. 아래를 **코드 탐색 후** 최소 변경으로 구현하고 검증까지 완료한다.

## 배경 / 사용자 요구 원문

> 녹화기능을 개선 하는 메타 프롬프트를 만들어줘
> 최초 사이트 1개만 저장 가능하게 되어 있는데 녹화하면서 여러 사이트를 이동 할수 있다. 이동시 해당 사이트도 허용될수있게 자동 N 개로 저장되어야 한다

현재 프리셋은 `urlPattern` **문자열 하나**만 가진다. 새 프리셋은 시작 탭 호스트만 넣고, 녹화로 다른 origin(예: `naver.com` → `shopping.naver.com`, `example.com` → `other.com`)에 가도 허용 목록이 늘지 않는다. 그 결과:

- `APPLY_PRESET` / 여정 재생이 `matchUrlPattern(preset.urlPattern, tab.url)` 한 줄에서 막힌다.
- 팝업 "현재 사이트" 배지·자동 적용 매칭도 첫 사이트만 본다.
- 편집 UI의 사이트 패턴 입력도 한 칸이다.

여정 녹화(R11)는 **같은 탭에서 페이지를 넘기는 것**까지는 된다. 이번 작업은 **넘긴 사이트를 허용 목록에 자동으로 N개 쌓는 것**이다.

## 목표 동작

1. 녹화 시작 시점의 사이트가 1번 허용 사이트다.
2. 녹화 중 탭이 다른 http(s) 사이트로 이동하면 그 사이트도 허용 목록에 **자동 추가**된다 (중복 없이, 방문 순서).
3. 종료 시 프리셋에 허용 사이트 **N개**가 저장된다.
4. 재생·자동 적용·팝업 배지는 **N개 중 하나라도 맞으면** 허용한다.
5. 이미 `urlPattern`만 있는 예전 프리셋은 그대로 동작한다 (`urlPatterns`가 없으면 `[urlPattern]`으로 본다).
6. 사용자가 편집에서 와일드카드(`*.naver.com`)를 넣어 둔 경우, 이미 커버되는 호스트는 다시 넣지 않는다.

## 핵심 설계

### 데이터

- `urlPattern: string` — **대표(첫) 사이트**. 그룹 실행 `patternToUrl`, 예전 인덱스/가져오기와 호환. 유지.
- `urlPatterns: string[]` — 허용 사이트 전체 (최대 20). 녹화 저장·편집 시 항상 정규화해 쓴다.
- 평문 인덱스에도 `urlPatterns`를 넣어 `AUTO_APPLY_CHECK`가 blob 복호화 없이 매칭할 수 있게 한다.

패턴 한 줄의 형식은 지금과 같다: `example.com`, `*.example.com`, `example.com/*`, `127.0.0.1:8765`.

### 녹화 중 수집

- `recordSessions[tabId].allowedSites: string[]`
- `RECORD_START`의 탭 URL → `urlToSitePattern`으로 1개 추가.
- `tabs.onUpdated`의 `changeInfo.url` / `appendNavigateIfRecording`에서 이동 URL도 추가.
- 수집 규칙:
  - `http:` / `https:`만.
  - `chrome://`, `chrome-extension://`, `about:`, `edge://`, `devtools:` 제외.
  - 값은 `hostname` 또는 포트가 있으면 `hostname:port` (IPv6는 `hostname` 그대로, 포트 있으면 `hostname:port` — `matchUrlPattern`이 `[::1]:8080`을 이미 처리).
  - 같은 패턴(대소문자 무시)은 한 번만.
- `RECORD_STOP` (주 저장 경로)에서 `mergeUrlPatterns(기존, session.allowedSites)` 후 `urlPatterns` + `urlPattern = urlPatterns[0]` 저장.
- 기존 와일드카드가 새 호스트를 이미 커버하면 추가하지 않음 (`patternCoversPattern`).

### 매칭

모든 사이트 검사 지점을 `matchPresetUrl(preset, url)` / `matchAnyUrlPattern(patterns, url)`로 통일:

- `APPLY_PRESET` (폼 + 여정 `startUrl`/`tab.url`)
- `AUTO_APPLY_CHECK`
- `applyAutoPreset` (`tabs.onUpdated`)
- popup `현재 사이트` 배지 / `is-matching`

`matchUrlPattern` 자체 판정(포트/IPv6/wildcard/경로)은 바꾸지 않는다.

### 팝업

- 사이트 패턴 입력을 **여러 줄 textarea**로 바꾼다 (한 줄에 하나, 쉼표도 허용).
- 안내: "녹화 중 방문한 사이트는 종료 시 자동으로 추가됩니다."
- 목록 카드 메타: 1개면 그대로, 2개 이상이면 `example.com 외 N개`.
- 저장 시 빈 줄 제거, 최대 20, 첫 줄이 `urlPattern`.

### 가져오기

- `urlPattern` 문자열이 없어도 `urlPatterns` 배열이 있으면 통과.
- 가져온 뒤 `urlPatterns`를 정규화하고 `urlPattern`을 첫 항목으로 맞춘다.

## 구현 상세

### background.js 헬퍼 (권장 시그니처)

```js
MAX_URL_PATTERNS = 20
urlToSitePattern(urlStr) → '' | 'host' | 'host:port'
getPresetPatterns(preset) → string[]   // urlPatterns 우선, 없으면 [urlPattern]
mergeUrlPatterns(existing, incoming) → string[]
matchPresetUrl(preset, urlStr) → boolean
```

`savePreset` 인덱스 entry:

```js
{ id, name, urlPattern, urlPatterns, autoApply, updatedAt }
```

`PRESET_CREATE`: `msg.urlPatterns`가 있으면 사용, 없으면 `[msg.urlPattern]`.

### 여정 재생 가드 (변경 후)

```js
const startOk = preset.startUrl && matchPresetUrl(preset, preset.startUrl);
const tabOk = matchPresetUrl(preset, tab.url);
```

예전처럼 대표 `urlPattern`만 보면, 녹화 시작은 A사이트인데 재생 버튼을 B사이트에서 누른 경우 계속 거절된다.

### 그룹 실행

`patternToUrl(preset.urlPattern)` 유지 — 대표(첫) 사이트를 연다. 그룹을 여정 재생으로 바꾸지 않는다.

## 금지 사항 (MUST NOT)

- `urlPattern` 필드를 삭제하거나 인덱스에서 빼기 (하위 호환).
- `matchUrlPattern` 판정 규칙을 다시 쓰기 (D18 포트/IPv6/경로 유지).
- `<all_urls>`를 좁히거나 `optional_host_permissions` 팝업을 새로 띄우기 (이미 content는 전 URL).
- 여정 프리셋 자동 적용을 켜기 (R11-7 유지).
- 네이버/특정 사이트 하드코딩.
- 그룹을 같은 탭 여정으로 바꾸기.
- `chrome://` 등을 허용 목록에 넣기.
- `as any` / `@ts-ignore` / 빈 catch.
- 기존 `test:replay` 폼 4필드·여정 클릭/Enter/navigate 케이스 깨기.
- `secure-store.js` 변경.

## 검증

- [ ] 한 사이트만 녹화하면 `urlPatterns` 길이 1, `urlPattern`과 동일
- [ ] A에서 녹화 시작 → B로 이동 → 종료 시 `urlPatterns`에 A, B (순서 유지, 중복 없음)
- [ ] 같은 호스트 경로만 바뀌면 사이트가 늘지 않음 (`example.com/form` → `example.com/price`)
- [ ] 기존 패턴 `*.example.com`이 있으면 `shop.example.com`을 또 넣지 않음
- [ ] B 사이트 탭에서 재생이 "대상 사이트가 아닙니다"로 거절되지 않음
- [ ] `urlPatterns` 없는 레거시 프리셋은 `urlPattern`만으로 매칭
- [ ] `chrome://` 이동은 허용 목록에 안 들어감
- [ ] 여정은 계속 자동 적용 제외
- [ ] `npm run check` / `test:encrypt` / `test:pii` / `test:replay` / `npm run build`
