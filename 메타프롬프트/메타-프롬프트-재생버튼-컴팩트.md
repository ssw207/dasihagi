# 메타프롬프트 — 재생 버튼 컴팩트화

## 목표 (사용자 요구 원문 포함)
사용자: "재생 버튼이 너무 크다 프리셋이 많을경우 UI UX 가 별로임"
→ 프리셋 카드의 재생 버튼이 flex:1로 크게 차지해 프리셋이 많을 때 목록이 길고 시각적으로 무거움. 버튼을 컴팩트하게 줄여 여러 프리셋이 있어도 깔끔하게 보이도록 개선.

## 변경 범위 (파일별)
- `popup/popup.css` — `.preset-card`, `.preset-actions`, `.preset-actions > .btn`, `.preset-actions > .btn-primary` 스타일 컴팩트화. 카드 간격, 버튼 패딩/폰트, 정렬 조정.
- `popup/popup.html` — 구조 변경 없음 (CSS만)
- `dist/` — `npm run build`로 재생성
- 테스트 — 시각 변경이므로 `check`/`build`/`replay` 유지

## 구현 상세
- 현재: `.preset-actions > .btn-primary { flex:1; padding:5px 0; font-size:11px }`, `.preset-actions { gap:6px }`, `.preset-card { margin-bottom:8px; padding:10px 12px }`
- 변경:
  - `.preset-card { padding:8px 10px; margin-bottom:6px }` — 카드 자체를 20% 컴팩트
  - `.preset-actions { gap:6px; justify-content:flex-end }` — 오른쪽 정렬로 목록이 길어도 정렬 안정
  - `.preset-actions > .btn { padding:4px 10px; font-size:11px; min-width:48px; flex:none }` — 버튼이 카드 전체를 차지하지 않음
  - `.preset-actions > .btn-primary { flex:none; padding:4px 12px; border-radius:6px }` — 재생 버튼도 작게, 단 primary 색상은 유지해 여전히 눈에 띔
  - 카드가 많을 때 세로 스크롤 부담을 줄이기 위해 `.preset-section-list { gap:6px }` 유지, 섹션 간격은 10px로
- 시각적 무게는 유지하되 크기만 축소 — primary blue는 그대로, hover 시만 강조

## MUST NOT
- 기능/데이터/저장 로직 변경 금지
- 재생 버튼의 접근성(44px 터치 타깃)을 36px 이하로 줄이지 않음 — 최소 32px 높이는 유지
- 다른 버튼(⋯ 더보기) 크기/위치는 유지

## 검증 방법
- `npm run check` — exit 0
- `npm run build` — exit 0
- 수동: 프리셋 8개 생성 후 목록에서 재생 버튼이 카드 폭의 100%가 아니라 오른쪽에 작게 보이고, 목록 전체 높이가 이전보다 20% 정도 줄어드는지
