# 메타프롬프트 — 소스 기준 문서 최신화

## 목표

사용자 요구 원문: **「소스를 기반으로 문서를 최신화 할것.」**

런타임 코드(`background.js`, `content.js`, `popup/`, `secure-store.js`, `pii-detect.js`, `manifest.json`, `package.json`, `test/*`)를 단일 기준으로 두고, 문서가 구현·검증 수·저장 키·한계를 그대로 말하게 한다. 제품 코드는 바꾸지 않는다.

## 구현 상세 (소스에서 확인한 사실)

- 버전 `0.1.0`, MV3, 권한 `storage`/`tabs`/`scripting`/`webNavigation`, `all_frames`
- 저장: `presets` 평문 인덱스 + `sec:preset:<id>` blob + `groups` + `vault_key_v1` + `ui:replayPace` + `ui:filterCurrentSite`. 세션: `runState`, `recordSessions` `{v:2, tabs, sessions}`
- 상한: import 프리셋 500 / 그룹 100 / 5MB, 필드 500/프리셋, 값 64KB, urlPatterns 20, delay 0~5000
- 재생 속도: fast delay≤40 afterNav 0 tabWait 8s waitEl 2.5s / normal 녹화값+200ms / 15s / 5s / slow delay×1.5+200 afterNav 1s tabWait 20s waitEl 8s
- 녹화 칩: top 또는 iframe `innerWidth≥240 && innerHeight≥160`
- SPA 적용 재시도: MutationObserver 300ms 디바운스, 최대 15초
- 가져오기 `appId`: `dasihagi` 또는 레거시 `form-preset-extension`
- popup은 `GET_CURRENT_URL` 대신 `tabs.query`. 핸들러는 background에 유지
- 같은 페이지 모달(열기→입력→확인 닫힘): `test:replay` + e2e G. window.open 닫힘은 R16
- 검증: check, build, encrypt **13/13**, pii **30/30**, replay **99/99**, qa **22/22**, e2e **71/71** (A~L)
- devDependencies: playwright, ffmpeg-static (README GIF)
- 유즈케이스 U1 “iframe이면 구멍”은 소스와 불일치 → 일반 iframe은 됨, sandbox는 한계

## MUST NOT

- `background.js` / `content.js` / `popup/` / `test/` / `manifest.json` / `dist/` 변경 금지
- 없는 기능을 요구사항에 추가 금지 (모달은 R11 확장, 신규 R19 아님)
- 기존 결정 D1~D38 문구를 재작성하지 않음 (요약 표에 D39만 추가)
- 사용자 매뉴얼을 개발자 스펙으로 바꾸지 않음

## 검증 방법

- 문서의 테스트 수·저장 키·메시지 타입이 소스 상수/스위치/`test/*.mjs`의 `ok`/`check`/`scenario` 개수와 같음
- 제품 코드 `git diff`에 런타임 파일이 없음
- `npm run check`는 문서만 고치면 기존과 동일 (실행은 선택)
