# 메타프롬프트 — 새 프리셋 버튼 삭제

## 목표 (사용자 요구 원문 포함)
사용자: "새프리셋 버튼 삭제"
→ 툴바의 `+ 새 프리셋` 버튼을 제거. 진입점은 `이 사이트 녹화`와 `캡처로 만들기`로 일원화.

## 변경 범위 (파일별)
- `popup/popup.html` — 툴바에서 `<button id="btn-new-preset">+ 새 프리셋</button>` 제거
- `popup/popup.js` — `$('#btn-new-preset').addEventListener(...)` 리스너 제거 (null 체크 없이 호출 시 에러 방지)
- `dist/` — `npm run build`로 재생성
- 테스트 — `check`/`replay`/`qa` 영향 없음

## 구현 상세
- HTML에서 해당 버튼 라인만 삭제, 나머지 툴바 레이아웃(녹화/캡처로 만들기/더보기)은 그대로 유지
- JS에서 해당 ID에 대한 addEventListener 호출 제거 — 다른 버튼 핸들러에는 영향 없음
- 빈 프리셋 생성은 `이 사이트 녹화`(현재 사이트 패턴으로 자동 생성) 또는 `캡처로 만들기`로 대체되므로 기능 손실 없음. 편집 화면은 `⋯ → 편집`으로 진입하므로 유지.

## MUST NOT
- `이 사이트 녹화` / `캡처로 만들기` 버튼 제거 금지
- 편집 뷰(`#preset-editor-view`) 자체 삭제 금지 — 기존 프리셋 편집은 유지
- 저장/캡처/녹화 로직 변경 금지

## 검증 방법
- `npm run check` — exit 0
- `npm run build` — exit 0
- 수동: 팝업 툴바에 `+ 새 프리셋`이 없고 `이 사이트 녹화`와 `캡처로 만들기`만 보이는지, `⋯ → 편집`은 정상 동작하는지
