# 메타프롬프트 — A 입력 팝업 → 확인 → 닫힘 녹화 검증

## 목표

사용자 요구 원문: **「가령A 사이트의 입력팝업이 뜨고 거기서 입력. 확인버튼누르면 팝업이 꺼지는 플로우인경우 이케이스도 테스트 성공했어?」**

답: 이전에는 그 플로우를 테스트하지 않았다. 지금 두 형태를 테스트하고, 실패하면 고친다.

1. **같은 페이지 모달**: A에서 입력 레이어가 뜨고, 입력 후 확인하면 레이어가 사라짐 (같은 tab).
2. **window.open 팝업**: A가 연 창에서 입력 후 확인하면 창이 닫히고 A 녹화는 유지.

## 변경 범위

- `test/record-replay-verify.mjs` — 위 두 시나리오
- `test/modal-popup.html` 또는 기존 journey/test-form에 모달 추가 후 E2E 가능하면 추가
- 실패 시에만 `content.js` / `background.js`
- REQUIREMENTS/decisions — 검증 범위 명시

## MUST NOT

- 기존 테스트 삭제 금지
- 사이트 하드코딩 금지

## 검증

- `npm run test:replay` 해당 케이스 PASS
- 가능하면 `npm run test:e2e`
