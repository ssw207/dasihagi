# 폼 프리셋

사이트에 매번 똑같이 넣는 값을 **한 번 저장**해 두고, **재생** 한 번으로 채우는 Chrome 확장 프로그램입니다.

사내 어드민 제휴 설정, 테스트 계정, 반복 기안처럼 **칸의 대부분이 같고 일부만 고치는 일**에 맞습니다. 개발자가 아니어도 쓸 수 있게 화면은 모두 한국어입니다.

이 문서는 **공개 GitHub 저장소에서 받아 설치하고 쓰는 방법**입니다. 이 페이지만 보면 됩니다.

## 준비물

| 필요한 것 | 확인 |
|-----------|------|
| **Google Chrome** | 일반 Chrome이면 됩니다 |
| **Git** | 저장소를 받을 때 씁니다 |
| **Node.js** | 확장을 빌드할 때 씁니다. [nodejs.org](https://nodejs.org/) LTS |

터미널(Windows는 PowerShell 또는 명령 프롬프트)에서 확인합니다.

```bash
git --version
node --version
```

버전 숫자가 나오면 됩니다. (Node는 `v18` 이상이면 충분합니다.)

## 설치 (GitHub에서)

### 1. 저장소를 내 컴퓨터로 받습니다

저장소: [https://github.com/ssw207/form-preset-extension](https://github.com/ssw207/form-preset-extension)

터미널에서 받고 싶은 폴더로 이동한 뒤:

```bash
git clone https://github.com/ssw207/form-preset-extension.git
cd form-preset-extension
```

### 2. 확장 프로그램을 빌드합니다

이 프로젝트는 번들러가 없습니다. 사용만 하면 아래 한 줄이면 됩니다.

```bash
npm run build
```

끝나면 아래처럼 **완성된 경로**가 나옵니다. 이 경로를 복사해 두세요.

```
빌드 완료 → C:\Users\이름\...\form-preset-extension\dist
```

macOS / Linux도 같습니다. 경로만 `/Users/이름/.../form-preset-extension/dist` 형태입니다.

> `npm install`은 **테스트를 돌릴 때만** 필요합니다. 설치·사용에는 없어도 됩니다.

### 3. Chrome에 올립니다

1. Chrome 주소창에 `chrome://extensions` 를 입력하고 Enter.
2. 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. 폴더 선택 창의 **경로 칸**에 2단계에서 복사한 `dist` 경로를 붙여넣고 Enter.

성공하면 목록에 **폼 프리셋**이 보이고, 툴바에 아이콘이 생깁니다. 아이콘이 안 보이면 퍼즐 조각(확장 프로그램) 버튼에서 **폼 프리셋**을 고정(핀)하세요.

### 4. 코드를 나중에 받았을 때 (업데이트)

저장소 폴더에서:

```bash
git pull
npm run build
```

그다음 `chrome://extensions`에서 폼 프리셋 카드의 **새로고침**을 누릅니다.

## 5분 안에 써 보기

실제 사이트 없이 저장소에 들어 있는 연습 페이지로 확인할 수 있습니다.

**터미널 하나**에서 저장소 폴더로 간 뒤:

```bash
npx --yes serve .
```

브라우저에서 엽니다.

- Windows: `http://localhost:3000/test/test-form.html`
- 주소가 다른 포트로 뜨면 터미널에 나온 주소를 씁니다.

> 파일을 더블클릭으로 열면 `file://` 입니다. 그때는 확장 프로그램 상세에서 **파일 URL에 대한 액세스 허용**을 켜야 합니다. 로컬 서버를 쓰는 편이 쉽습니다.

연습 페이지가 열린 상태에서:

1. 툴바의 **폼 프리셋**을 누릅니다.
2. **이 사이트 녹화**를 누릅니다. 프리셋이 만들어지고 녹화가 시작됩니다.
3. 페이지에서 이름·이메일을 넣고, 부서를 고르고, 약관에 체크합니다.
4. 화면 위 **종료** (빨간 칩) 또는 팝업의 **종료**를 누릅니다.
5. 입력칸을 지운 뒤, 팝업에서 해당 카드의 **재생**을 누릅니다. 값이 다시 채워지면 성공입니다.

## 일상적으로 쓰는 방법

### 이 사이트 녹화 (가장 쉬운 시작)

1. 값을 넣을 사이트(또는 사내 어드민)를 엽니다.
2. **폼 프리셋** → **이 사이트 녹화**.
3. 평소처럼 입력·선택·클릭합니다.
4. **종료**하면 자동 저장됩니다.
5. 다음에 **재생**하면 같은 순서로 다시 실행됩니다.

이름과 사이트 패턴을 직접 정하려면 **+ 새 프리셋**으로 만든 뒤, 카드의 **⋯ → 녹화**를 누르면 됩니다.

### 화면에서 자주 쓰는 것

| 보이는 것 | 하는 일 |
|-----------|---------|
| **이 사이트 녹화** | 지금 사이트로 프리셋을 만들고 바로 녹화 |
| **현재 사이트만** | 지금 탭과 맞는 프리셋만 목록에 표시 (기본 켜짐) |
| **재생** | 저장한 값·행동을 실행 |
| **⋯** | 녹화, 편집, 삭제 |
| **재생 속도** 빠름 / 보통 / 느림 | 페이지 이동 뒤 쉬는 시간. 사내는 **빠름**, 외부는 **보통** 또는 **느림** |
| **녹화 중** 배너 | 팝업을 다시 열어도 녹화 중이면 보입니다. **종료**로 저장합니다 |

목록 왼쪽 칸을 여러 개 고른 뒤 **선택 삭제**로 한 번에 지울 수 있습니다. **전체 선택**도 있습니다. 확인 창 없이 지우지 않습니다.

### 편집

카드 **⋯ → 편집**:

- 프리셋 이름, 사이트 패턴(한 줄에 하나), 필드 표시 이름을 고칩니다.
- 값은 다시 녹화하거나 칸에서 직접 고칩니다.
- **페이지 진입 시 자동 적용**을 켜면, 그 사이트에 들어올 때 폼이 채워집니다. (검색·클릭이 들어 있는 **여정** 프리셋은 자동 적용되지 않습니다.)

### 여정 (한 프리셋으로 여러 페이지)

검색 → 클릭 → Enter → 페이지 이동까지 **한 프리셋**에 이어 기록됩니다.

- 페이지가 바뀌어도 **녹화 중** 칩이 다시 나타납니다.
- A에서 연 **팝업/새 탭**에서도 녹화가 이어집니다. 팝업을 닫아도 A 쪽 녹화는 유지됩니다.
- 같은 페이지의 **입력 레이어**(열기 → 입력 → 확인으로 닫힘)도 기록됩니다.
- 사내 어드민이 **iframe** 안에 있어도 그 안에서 녹화·재생됩니다. 아주 작은 iframe에는 칩이 안 보일 수 있고, 그때는 바깥 페이지 칩에서 종료하면 됩니다.
- 다른 사이트로 이동하면 허용 목록에 자동으로 추가됩니다.

광고·로그인·검색 순위가 자주 바뀌는 사이트는 같은 버튼을 못 찾을 수 있습니다. 그때는 그 단계만 다시 녹화하세요.

### 그룹 (페이지마다 폼만 순서대로)

제휴사 설정처럼 **A페이지 폼 → B페이지 폼**만 채울 때는 그룹이 맞습니다. 클릭·검색까지면 여정을 쓰세요.

1. 페이지마다 프리셋을 먼저 만듭니다.
2. 팝업 **그룹** 탭 → **+ 새 그룹**.
3. 프리셋을 순서대로 스텝에 넣습니다.
4. 스텝마다:
   - **수동**: 값만 채움. 저장/제출은 내가 하고 **다음 단계**.
   - **자동 제출**: 채운 뒤 제출 버튼까지 클릭 (셀렉터 예: `button[type="submit"]`).
5. **실행**. 각 스텝이 **새 탭**으로 열립니다. 아이콘에 `2/3`처럼 진행이 보입니다. **중지**로 끊을 수 있습니다.

### 캡처 (칸 이름을 직접 정하고 싶을 때)

1. 프리셋을 만든 뒤 **편집**에서 **캡처 모드 시작**.
2. 파란 점선이 뜬 칸을 클릭합니다.
3. 표시 이름 Enter → 값 Enter.

녹화로 부족한 칸만 캡처로 보완해도 됩니다.

### 내보내기 / 가져오기

목록 **더보기**에 있습니다.

- 내보내기: 프리셋·그룹이 JSON 파일로 저장됩니다. **값의 실문이 들어 있으니** 파일을 안전하게 보관하세요.
- 가져오기: 기존 항목은 그대로 두고 새 항목이 추가됩니다. 덮어쓰지 않습니다.

## 값과 개인정보

- 저장되는 **모든 값**은 이 브라우저 안에서 암호화됩니다. 저장소를 열어봐도 내용이 보이지 않습니다.
- 휴대폰·이메일·비밀번호처럼 개인정보로 보이는 칸은 목록에서 `••••••`로 가립니다. 복사·재생할 때는 실제 값이 쓰입니다.
- 암호화 키는 이 Chrome 프로필에 있습니다. 다른 PC로 옮기려면 **내보내기 → 가져오기**를 쓰세요.
- “암호화 키가 없/손상”이 뜨면 이 프로필에서 예전 프리셋을 풀 수 없습니다. 백업 JSON이 있으면 가져오기로 복구하세요.

## 사이트 패턴

편집 화면에서 한 줄에 하나씩 넣습니다. 녹화 중 방문한 사이트는 종료 시 자동으로 붙습니다.

| 적는 예 | 의미 |
|---------|------|
| `example.com` | 그 사이트 모든 페이지 |
| `*.example.com` | 하위 도메인 포함 |
| `example.com/admin/*` | admin 경로만 |
| `127.0.0.1:3000` | 로컬 서버 (포트 포함) |

## 이 제품으로 하지 않는 일

- 좌석 오픈런, 대기열, 캡차, 보안 키패드
- 파일·이미지 첨부 (`파일 선택` 칸)
- `chrome://` 같은 크롬 내부 페이지
- sandbox로 막힌 iframe, 데스크톱 전용 프로그램

재생은 **칸을 채우고 클릭을 재현**합니다. 결제·상신·전송 버튼은 가급적 직접 누르세요. (그룹의 자동 제출은 필요할 때만)

## 문제가 생기면

| 증상 | 해결 |
|------|------|
| 설치 후 아이콘이 없음 | `chrome://extensions` 개발자 모드 확인. 툴바에서 확장 고정 |
| `npm run build`를 찾을 수 없음 | 저장소 **루트** 폴더인지 확인 (`package.json`이 보여야 함) |
| 값이 안 채워짐 | 확장 카드 **새로고침** + 사이트 새로고침. 사이트가 바뀌었으면 다시 녹화 |
| iframe 어드민에서 안 됨 | 확장 새로고침 후 **iframe 안**에서 녹화. 칩이 없으면 바깥 페이지 칩에서 종료 |
| 팝업 창에서 녹화가 안 됨 | 확장을 최신으로 빌드·새로고침했는지 확인. A에서 연 창이어야 이어집니다 |
| 재생이 너무 느리거나 너무 빠름 | 팝업 **재생 속도**를 바꿉니다. 사내 → 빠름 |
| chrome:// 에서 녹화 버튼이 비활성 | 정상입니다. 일반 웹/사내 어드민에서 쓰세요 |
| 사이트 개편 후 실패 | 해당 칸을 다시 녹화하거나 캡처 |
