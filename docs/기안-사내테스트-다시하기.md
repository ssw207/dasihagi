## 1. 기안 개요

| 항목 | 내용 |
|------|------|
| 제목 | 사내 테스트 용도 한정, Chrome 확장 **다시하기** 개발 및 파일럿 |
| 목적 | 스테이징·폐쇄망 어드민·로컬에서 반복되는 폼 입력·테스트 계정 전환을, 녹화한 흐름의 **재생**으로 줄인다 |
| 승인 | ① 사내 테스트 전용 개발 인정 ② 소수 파일럿 사용 ③ 웹스토어·전사 필수 설치·운영 사용은 **불허** (2026-08-30) |

### 한 줄

사이트에서 한 번 한 **입력·클릭·이동**을 녹화해 두고, 사내 테스트 화면에서 **재생**으로 다시 실행한다. 제출·결재·결제는 사람이 한다.

## 3. 배경과 문제

테스트·운영 준비에서 같은 웹 화면에 **거의 같은 값**을 여러 번 넣는다.

| 누가 | 지금 하는 일 | 깨지는 지점 |
|------|--------------|-------------|
| QA / 기획 | 구매자·판매자·관리자 값을 엑셀에서 복사 | 한 칸 오타, 잘못된 계정으로 시나리오 진행 |
| 제휴 운영 | 제휴사만 다르고 필드 30칸이 같음 | 약관·부가세 유형 체크 누락, 건당 수 분 |
| 개발 | localhost 로그인·시드 데이터 | 매일 같은 폼을 손으로 채움 |

기존 도구가 안 맞는 이유:

- **비밀번호 관리자** — 로그인 칸. 제휴 설정 30칸·약관 체크·셀렉트는 약함.
- **Playwright / RPA** — 개발자 도구. 이미 로그인한 Chrome, 폐쇄망 어드민, “버튼 하나 누르고 확인”과 설치가 다름.
- **엑셀 일괄 업로드** — 사이트가 받아 주지 않으면 불가.

필요한 것은 별도 봇이 아니라, **보고 있는 페이지에서 한 일을 저장하고 다시 하는 것**이다.

v0.1.0은 이 문제를 푸는 확장이 이미 동작하는 상태다. 본 기안은 그 코드를 **사내 테스트 한정으로 개발·파일럿하는 것**을 공식화한다.

## 4. 제안 내용

### 4.1 제품 위치

| | 다시하기 (이번 기안) | 아닌 것 |
|--|----------------------|---------|
| 실행 | 사용자가 이미 쓰는 Chrome | 별도 RPA, Node 스크립트 |
| 대상 | 사내 테스트 폼, 고정 DOM 어드민, 로컬 | 좌석 오픈런, 대기열, 캡차, 운영 결제 |
| 단위 | 프리셋(한 폼 또는 한 흐름), 그룹(폼을 순서대로) | 사이트 전용 스크래퍼 |
| 제출 | 기본은 채움. 자동 제출은 그룹에서만 사용자가 고름 | 결제·상신을 대신 누름 |
| 데이터 | 이 Chrome 프로필 안 암호화 | 서버, 팀 클라우드 |
| 배포 | 내부 `dist/` | 웹스토어, 고객 설치 패키지 |

이름 **다시하기**는 “한 일을 다시 한다”는 뜻이다. 기안·공지·교육에서 **매크로, 자동화, 봇**이라는 말은 쓰지 않는다 (제품 결정 D33, 기획팅 K5).

### 4.2 이번 기안에서 하는 일 (In)

파일럿 사용자가 README 기준으로 아래를 쓸 수 있게 **유지·배포·안내**한다. 새 기능을 이 기안에 넣지 않는다.

- **이 사이트 녹화** → 평소 입력·클릭 → **종료** → **재생**
- 페이지 이동·팝업이 있는 **여정**은 같은 탭에서 이어 녹화·재생
- 페이지마다 폼만 있으면 **그룹**으로 순서대로 (스텝마다 새 탭, 제출은 수동 기본 권장)
- 사내 어드민이 iframe 안이어도 그 프레임에서 녹화·재생 (sandbox iframe 제외)
- 재생 속도 **빠름** (사내·봇 제한 없음). 도메인을 코드에 넣지 않음
- 목록에서 휴대폰·이메일처럼 보이는 값은 가림. 저장소에는 프리셋 전체 암호화
- 연습 페이지(`test/test-form.html`)로 5분 설치 확인

상세 수용 기준은 REQUIREMENTS R1~R18. 기안이 기술 명세를 복제하지 않는다.

### 4.3 하지 않는 일 (Out) — 승인 범위에서 제외

README·제품 기획서와 같다. 추가로 **사내 기안 Out**을 못 박는다.

| 항목 | 이유 |
|------|------|
| Chrome 웹스토어 / 고객사 배포 | K1. 테스트 도구를 제품으로 바꾸지 않음 |
| 전사 필수 설치, MDM 강제 | 권한(`<all_urls>`)·오용 위험 |
| 운영(프로덕션) 사이트에서 재생 | K2. 실데이터 오염 |
| 운영 계정 비밀번호·실고객 PII 저장 | K3 |
| 서버 동기화, 팀 공유 백엔드 | K4 |
| 좌석 오픈런, 대기열, 캡차, 보안 키패드 | K5 |
| 파일·이미지 첨부 재생 | 확장이 채울 수 없음 |
| `chrome://` , sandbox iframe, Shadow DOM 전용 위젯 | 플랫폼 한계 |
| 결제·상신·전송을 확장이 대신 누르는 것을 권장 | 안전. 녹화되어 있어도 사람이 누름 |
| 이 기안에서 신규 기능 일정 | K7 |

## 5. 사용 대상과 환경

### 5.1 파일럿 대상 (소수)

| 대상 | 쓰는 것 | 쓰지 않는 것 |
|------|---------|--------------|
| QA / 기획 | 테스트 페르소나 프리셋 전환, 클릭 복사 | 운영 URL, 자동 적용으로 여러 페르소나 섞기 |
| 제휴 운영 | 제휴 유형별 프리셋 + 그룹, 재생 속도 빠름 | 실운영 정산 계좌를 프리셋에 저장 |
| 개발 (스테이징) | localhost·시드, 포트 포함 패턴 | 운영 배포 파이프라인에 확장 포함 |

전 직원 공지·강제 설치는 하지 않는다. 인원·기간은 승인 후 사용 부서가 정한다.

### 5.2 허용 환경

- 사내 스테이징, 폐쇄망 어드민, 로컬(`localhost`, `127.0.0.1:포트`)
- 데스크톱 Chrome. iOS 크롬 확장 없음

### 5.3 금지 환경

- 운영(프로덕션) 서비스 URL
- 외부 예매·대기열·캡차가 있는 사이트에서의 “성공률 보장” 사용
- 고객 PC, 협력사 공용 PC에 임의 설치 (IT 배포 정책이 따로 있기 전까지)

## 6. 보안·권한·개인정보

승인권자가 확인할 세 문장:

1. **값은 이 Chrome 프로필 안에서만 암호화되어 저장된다.** 프리셋 통째 AES-256-GCM (`sec:preset:<id>`). 서버로 올리지 않는다.
2. **휴대폰·이메일처럼 보이는 칸은 목록에서 가린다.** 감지는 마스킹용이다. 감지가 빠져도 저장소 평문에는 필드 값이 없다.
3. **내보내기 파일에는 실값이 들어간다.** 테스트 데이터만 내보낸다. 메신저·메일로 돌리지 않는다. 다른 PC는 가져오기로만 옮긴다.

### 6.1 권한 (`manifest.json`)

`storage`, `tabs`, `scripting`, `webNavigation`. content script는 `<all_urls>` + `all_frames`.

교차 origin iframe DOM을 부모가 읽지 않는다. 각 프레임 스크립트가 자기 문서만 다룬다. 이 권한이 넓으므로 **전사 배포를 하지 않는다** (K1).

### 6.2 보호 수준 (과장 금지)

로컬 열람, 백업 유출, 문자열 검색 방어. OS 키체인 수준은 확장만으로 불가. 키가 없거나 손상되면 이 프로필의 예전 항목을 풀 수 없다.

### 6.3 파일럿 수칙 (의무 안내)

- 프리셋에는 **테스트 계정·더미 값**만 넣는다.
- 운영 비밀번호, 실고객 주민번호·카드번호·실계좌를 넣지 않는다.
- 자동 적용은 페르소나가 여러 개면 끈다. 잘못된 계정으로 저장되는 사고를 막는다.
- 그룹 스텝 제출은 **수동**을 기본으로 안내한다. 저장이 일어나는 버튼은 사람이 누른다.
- 확장 삭제·프로필 이동 시 로컬 값은 그 프로필에 남거나 사라진다. 필요하면 암호화 전 내보내기가 아니라 **내부 보관 규칙에 맞는 백업**만 한다.

## 7. 배포·설치·운영

### 7.1 설치 (파일럿)

1. 저장소 clone (또는 IT가 전달한 소스/`dist`)
2. Node.js LTS, `npm run build` → `dist/` 경로 확인
3. Chrome `chrome://extensions` → 개발자 모드 → **압축 해제된 확장 프로그램을 로드** → `dist` 선택
4. 연습 페이지에서 녹화 → 칸 지우기 → 재생으로 설치 확인

쓰기만 하면 `npm install`은 필요 없다. 상세는 README.

### 7.2 업데이트

`git pull` → `npm run build` → 확장 카드 **새로고침**. 스토어 자동 업데이트 없음.

### 7.3 검증 (개발·QA, 사용자는 불필요)

`npm run check` / `build` / `test:encrypt` / `test:pii` / `test:replay` / `test:qa` / `test:e2e`

E2E는 실제 Chromium에 `dist`를 로드한 로컬 페이지다. 실사이트·로그인은 검증하지 않는다.

### 7.4 운영 지원

- 사이트 개편 후 재생 실패 → 해당 단계 재녹화 또는 캡처로 칸 보완
- 봇 재시도·캡차 우회 패치 요청은 받지 않음
- 장애 창구는 파일럿 채널(사용 부서·개발). 대고객 CS 없음

## 9. 기대 효과와 성공 조건

### 9.1 기대

| 효과 | 파일럿에서 보는 방법 |
|------|----------------------|
| 반복 입력 시간 감소 | 제휴 한 건: 재생 후 이름·사업자만 수정. 수 분 → 수십 초 수준인지 |
| 누락 감소 | 고정 체크·셀렉트가 빠지지 않는지 |
| 페르소나 전환 | QA가 계정 셋을 카드 **재생**으로 바꾸는지 |
| 신뢰 | 목록 민감값 마스킹, 저장소 평문에 필드 값 없음 |

### 9.2 성공으로 보지 않는 것

- 동적 검색·광고·로그인 벽이 있는 외부 사이트에서 재생이 항상 성공
- 운영 결제·상신을 확장이 대신하는 것
- 설치 수, 스토어 별점

### 9.3 실패 시

그 단계만 다시 녹화한다. 제품 한계(가상 리스트 좌석, sandbox iframe, 파일 첨부)는 기안 Out이다.
